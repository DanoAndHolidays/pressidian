代码实现

每次将大于待插入元素的前面的元素后移一位，再将待插入元素移入空出的位置： ![Pasted image 20251103144227](../../../_assets/7dde8fe-Pasted image 20251103144227.png) 空间复杂度：O(1)，时间复杂度：O(n^2)，稳定。在待排序的记录基本有序的时候，时间复杂度能达到O(1)的级别。

优化

在待插入元素的前面的部分是有序的，可以使用折半查找优化： ![Pasted image 20251103145002](../../../_assets/7f8ed8a-Pasted image 20251103145002.png) ![Pasted image 20251103145042](../../../_assets/c3598fc-Pasted image 20251103145042.png) ![Pasted image 20251103145127](../../../_assets/cce519d-Pasted image 20251103145127.png) 此时low在high的右侧，停止折半查找，high右侧的元素均大于i所指元素，low左侧则均小于。在low和high中间的位置就是待插入元素的插入位置： ![Pasted image 20251103145257](../../../_assets/4c32cb0-Pasted image 20251103145257.png) 特殊的，在这种情况下，不应该停止查找，而应该是在右侧继续寻找60，确保算法的稳定性： ![Pasted image 20251103145651](../../../_assets/1a74605-Pasted image 20251103145651.png) ![Pasted image 20251103145812](../../../_assets/6969104-Pasted image 20251103145812.png) 这时，插入60就能够保证算法的稳定性： ![Pasted image 20251103145845](../../../_assets/dcd9a88-Pasted image 20251103145845.png) ![Pasted image 20251103150256](../../../_assets/e822663-Pasted image 20251103150256.png)
